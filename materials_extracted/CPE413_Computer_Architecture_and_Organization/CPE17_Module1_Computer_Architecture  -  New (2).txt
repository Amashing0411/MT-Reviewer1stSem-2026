Two Sides of the Same Machine
Architecture is the “what” — Organization is the “how”
C O MPU TE R  AR C H I TE C TU R E
The conceptual design and fundamental operational structure 
of a computer system. It deals with the high-level design of a 
computer’s hardware components and their interactions.
Includes: instruction set, data types, addressing modes, and visible 
registers.
C O MPU TE R  O R G AN I Z AT I O N
The operational structure and implementation of computer 
systems. It focuses on how the hardware components are 
connected and interact with each other to execute instructions.
Includes: how circuits, signals, and physical hardware are actually wired
together.

Key Aspects
Three concepts that tie architecture and organization together
ISA
Instruction Set Architecture
Defines the set of instructions the CPU 
can execute and how they are encoded.
μ-ARCH
Microarchitecture
The implementation of the ISA —
including CPU design, pipelining, and 
parallel processing.
MEM
Memory Hierarchy
The organization of different memory 
types (registers, cache, main, secondary) 
to optimize access time and 
performance.

History Highlights
Milestones that shaped modern computing
1642 Pascal’s Calculator
One of the first mechanical calculators, by Blaise Pascal.
1837 Babbage’s Analytical Engine
Never completed, but laid the groundwork for modern computing.
1945 ENIAC
First general-purpose electronic digital computer, using vacuum tubes.
1945 Stored-Program Concept
John von Neumann’s idea: instructions stored in memory alongside 
data.
1964 IBM System/360
A family of compatible computers using integrated circuits.
1971 Intel 4004
First commercially available microprocessor, enabling personal 
computers.
1980s+ Personal Computers
Widespread PC adoption brought GUIs, the internet, and modern 
software.
Today AI & Quantum Computing
Self-learning systems and quantum/neuromorphic computing push the 
frontier.

Inside the CPU: Processors
The “brain” of the computer — fetches, examines, and executes
CPU Organization The datapath consists of registers, the ALU, and buses connecting the pieces; registers feed two ALU input registers.
Instruction Execution Each instruction runs through the fetch–decode–execute cycle — central to how every computer operates.
RISC vs. CISC RISC (Reduced Instruction Set Computer) is contrasted with CISC (Complex Instruction Set Computer).
Instruction-Level Parallelism The parallel or simultaneous execution of a sequence of instructions in a program.
Processor-Level Parallelism In a multiprocessor system, each processor executes a different thread on the same or different data.

Primary Memory
Where programs and data are stored during execution
Bits
The basic unit of memory — a binary digit 
that holds a 0 or a 1.
Memory Address
Each memory cell has a unique number, its 
address, by which programs refer to it.
Byte Ordering
Bytes in a word can be numbered left-to-
right or right-to-left — a choice with major 
implications.
Error-Correcting Codes
Guards against occasional errors using 
error-detecting or error-correcting codes.
Cache Memory
Temporarily stores frequently used 
instructions and data for faster CPU access.

The Memory Hierarchy
Organizing memory to minimize access time (locality of reference)
Level 0 — CPU Registers
Fastest · smallest · highest cost per bit
Level 1 — Cache Memory (SRAM)
Very fast · small · close to the CPU
Level 2 — Main Memory (DRAM)
Fast · medium size · volatile
Level 3 — Magnetic Disk
Slower · large · non-volatile
Level 4 — Optical Disk / Magnetic Tape
Slowest · largest · lowest cost per bit
↑ SPEED & COST
↓ CAPACITY

Relevant Tools & Standards
Four components required to implement a computerized input-process-output model

The physical mechanisms to input, output, manipulate, and process 
data — the tangible part of the system.
Computer Software
Programs that tell the computer what to do: system software (e.g.

Architecture Is Engineering Design Under Constraints
Eight factors that shape every design decision
1
Functionality
Does the design work and meet user 
needs? (usability, satisfaction, 
efficiency, effectiveness)
2
Cost
Resources needed to conceive, 
design, produce, and maintain the 
product
3
Performance
Coordination of conditions that 
produce desired results: input, 
output, efficiency, quality, outcome
4
Size
Physical space taken up by the 
system solution
5
Power & Energy
Energy required to perform its 
function — often traded off against 
cost
6
Time to Market
Time from concept to release — or 
until the first unit is sold
7
Maintainability
Probability a failed component can 
be restored within a specified time
8
Safety
Embedding health & safety 
considerations from the earliest 
design stages

Key Takeaways
1 Architecture defines what a computer can do; organization defines how it does it.
2 A computer system is built from the CPU, memory, storage, I/O, and a shared bus.
3 Computing has evolved through six generations — from mechanical devices to AI.
4 The CPU cycles through fetch–decode–execute for every single instruction.
5 Memory is organized in a hierarchy that trades speed for capacity.
6 Good architecture is engineering design under real-world constraints: functionality, cost, performance, size, power, time-to-market, maintainability, and safety.
